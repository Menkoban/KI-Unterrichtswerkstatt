# Prüf-Checkliste Material (E7, Lehrkraft 2026-10-13: A)

Gilt vor jeder Freigabe. Drei Stufen nach Baustein 8; jede Korrektur der Lehrkraft wird hier als
eigener Prüfpunkt ergänzt (mit Datum). Befunde gehen in den Prüfbericht als **Fehler / Warnung / Hinweis**.

Kennzeichnung: **[A]** = automatisch geprüft (`werkzeug/vorlagen/alle_bauen.py`, `pruefen()`),
**[S]** = Sichtprüfung durch einen frischen Helfer am Bild, **[L]** = Leser-Test.
