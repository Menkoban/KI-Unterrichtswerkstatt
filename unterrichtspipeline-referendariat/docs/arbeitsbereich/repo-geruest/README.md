# Arbeitsbereich Referendariat (persönlich)

Persönlicher Arbeitsbereich zur
Unterrichtspipeline (Werkzeug im Nachbarordner `unterrichtspipeline-referendariat`).
Das Werkzeug (Skills, Regeln, Vorlagen) liegt dort und ist für alle gleich; **hier**
liegt alles, was nur dieser Lehrkraft gehört.

**Privat und muss es bleiben:** Planungen echter Klassen (nur Kürzel), Besuche,
Profil, eigene Quellen.

| Ordner | Inhalt |
|---|---|
| `Profil/` | Lehrkraft-Profil: persönliche Vorgaben für jede Planung; Seminar-Einstellungen |
| `Ref/` | Ref-Akte: Stundenübersicht, Besuche, Fristen, Dokumentation der Ausbildung, KI-Verzeichnis |
| `<Fach>/<Beruf oder Bildungsgang>/<Lernfeld oder Thema>/<Lernsituation>/` | wiederverwendbare Planungsgrundlagen, Modellbetrieb je Beruf; ein Ordner je Fach aus dem Profil |
| `Unterricht/<Fach>/<Schuljahr>_<Klasse>/<LF>/<LS>/<Stunde>/` | klassenbezogene Akten bis zur einzelnen Stunde |
| `Quellen/` | eigene Literatur und Unterlagen |
| `.daten/` | interne Daten der Pipeline (nicht von Hand bearbeiten) |

Die Struktur entspricht Abschnitt 3b im Konzept des Werkzeugs. In der späteren App ist
dieser Ordner der lokale Arbeitsbereich jedes Nutzers; Git ist nur die Sicherung.
