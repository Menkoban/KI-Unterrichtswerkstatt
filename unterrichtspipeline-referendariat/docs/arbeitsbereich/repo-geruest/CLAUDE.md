# Arbeitsbereich Referendariat (persönlich)

Dies ist der **persönliche Arbeitsbereich** einer Lehrkraft im Vorbereitungsdienst
(BBS; Schule, Seminar und Fächer stehen im Profil). Das Werkzeug liegt in
`unterrichtspipeline-referendariat`; dort stehen Skills, Konzept
(`docs/KONZEPT.md`) und Arbeitsweise. Dieses Repository enthält nur Daten.

- Skills schreiben ihre Ergebnisse hierher, nie ins Werkzeug-Repository.
- Struktur nach Abschnitt 3b des Konzepts; Benennung der Stunden-Ordner
  `JJJJ-MM-TT_LFnn-LSnn-UEn_Kurzthema`.
- Ausgaben für die Lehrkraft als DOCX; interne Daten in `.daten/`.
- Lernende nur als Kürzel (S01 …), nie mit Namen.
- Keine Modellbezeichnungen in Dateien, die ins Repository gehen.
- Jede Änderung committen und pushen; Git ist die einzige Sicherung.
