# Materialpipeline Referendariat (Pipeline 2)

Aus dem **Materialauftrag** einer Stunde (Schritt 14 der
[Unterrichtspipeline](../unterrichtspipeline-referendariat))
entsteht hier fertiges, handlungsorientiertes Unterrichtsmaterial:
DOCX, XLSX, PPTX, interaktive HTML-Simulationen und Videos.
Die Moodle-Pipeline (Pipeline 3) wandelt es danach nur noch um.

```
Pipeline 1 Planung  →  Pipeline 2 Material (dieses Repo)  →  Pipeline 3 Moodle
```

**Privat und muss es bleiben:** Im Quellenordner liegen Scans und Auszüge gekaufter
Fachbücher.

## Ordner

| Ordner | Inhalt |
|---|---|
| `auftraege/` | eingehende Materialaufträge aus Pipeline 1 (je Stunde) |
| `quellen/` | Fachbücher, Normen und Vorschriften, Herstellerunterlagen; `_karte/` = maschinelle Quellenkarte |
| `bibliothek/<Fach>/<LF>/` | Material, das über eine Lernsituation hinaus trägt (Werkzeugkoffer, Checklisten, Simulationen) |
| `material/<Fach>/<Beruf>/<LF>/<LS>/<DS>/` | fertiges Material je Stunde, abgelegt je Lernsituation |
| `vorlagen/` | DOCX-, PPTX- und XLSX-Vorlagen |
| `skills/` | Skills der Materialpipeline |
| `werkzeuge/` | Skripte und Einrichtung (Schaltbilder, OCR, Prüfer) |
| `docs/` | Konzept und Entscheidungen |

## Ablauf (Kurzfassung)

M1 Auftrag lesen · M2 Bibliothek prüfen · M3 Quellen und Recherche · M4 Inhalt ·
M5 Grafik, Interaktion, Video · M6 Prüfer · M7 Freigabe, Ablage, Übergabe an Pipeline 3.
Einzelheiten: [`docs/KONZEPT.md`](docs/KONZEPT.md).
