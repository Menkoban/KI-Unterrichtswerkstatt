Moodle-Exporte laden

CSV-Dateien hierher ziehen oder auswählen. Erkannt werden:

  • Testergebnisse: Test → Ergebnisse → Bewertungen → „Herunterladen“ als CSV (Eingangstest, Selbsttests, Generalprobe, Abschlusstest).
  • Selbsteinschätzung vorher/nachher: Feedback → Antworten anzeigen → „Herunterladen“ als CSV.
  • Bewertungsübersicht: Bewertungen → Export → Textdatei (CSV), Tests in Prozent, Sterne in Punkten – für „Kacheltests und Sterne“ (erster und zweiter Versuch, Sterne je Schritt).

Die Daten bleiben in diesem Browserfenster. Nichts wird gespeichert oder gesendet; nach dem Schließen ist alles weg. Lernende erscheinen so, wie sie im Export stehen.
